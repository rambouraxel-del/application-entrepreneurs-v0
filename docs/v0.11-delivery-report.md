# Rapport de livraison — V0.11 Centre de paramètres

## Statut

La branche `v0.11-settings-center` est prête pour la validation humaine finale. Elle n'est ni fusionnée ni taguée.

## Correctifs de finalisation

- raccordement des paramètres aux moteurs V0 existants plutôt qu'à de simples objets globaux inutilisés ;
- apparence globale chargée sur toutes les pages post-connexion ;
- référentiels fiabilisés : identifiants uniques, `legacyId` optionnel, anciennes valeurs conservées et désactivation privilégiée ;
- profil de démonstration activé sans réinitialiser les autres sections ;
- recherche enrichie, accueil complété et import JSON résumé avant confirmation ;
- source unique d'alertes affichées sur le Dashboard, pilotée par les réglages ;
- Agenda : vue, plage horaire, pas, durée, jours travaillés, week-ends et statut initial réellement appliqués aux vues et aux nouveaux rendez-vous en mémoire ;
- Trésorerie : horizon, seuils, visibilité prévu/réalisé, catégories et récurrences réellement appliqués au module et à sa modale ;
- snapshots historiques de devis/factures préservés, paramètres courants appliqués aux nouveaux documents seulement ;
- réglages incompatibles avec la V0 explicitement classés préparatoires V1.

## Tests exécutés

- `node --check` sur tous les scripts modifiés ;
- store : sauvegarde, rechargement, reset section/global, import, export et migration ;
- référentiels : unicité, collisions id/legacyId et absence de `legacyId` hérité ;
- démonstration non destructive ;
- neuf recherches obligatoires ;
- propagation des réglages, numérotation, snapshots, Agenda, Trésorerie et alertes dédupliquées ;
- chemins du bootstrap et présence de la feuille d'apparence globale.

Tous ces contrôles automatisés passent.

## Limite de recette

Une tentative de recette Chromium headless a été effectuée, mais l'environnement d'exécution n'a pas rendu même une page HTML vide. La vérification visuelle finale dans un navigateur utilisateur reste donc nécessaire : rendu responsive, interactions de la page Paramètres et absence d'anomalie visuelle sur les pages principales.
